# 1️⃣ 개념 정리 

## 01. 불필요한 데이터 삭제하기

데이터 정제: 수집한 데이터에서 잘못된 부분을 고치거나 불필요한 부분을 삭제해서 분석에 맞게 준비하는 과정. 정제가 제대로 안 되면 분석 결과가 왜곡되어 잘못된 의사 결정으로 이어질 수 있다. 정제와 함께 분석에 적합한 형태로 바꾸는 과정 전체를 데이터 랭글링(먼징)이라고 부른다.

**불필요한 열 삭제** (남산도서관 대출 데이터 ns_df)
- `loc`에 슬라이싱(`ns_df.loc[:, '번호':'등록일자']`)을 쓰면 연속된 열만 선택할 수 있어서, 중간에 있는 '부가기호' 열만 빼려면 불리언 배열을 쓴다.
- 판다스 배열은 값과 비교하면 모든 원소와 하나씩 비교하는 원소별 비교가 된다. `ns_df.columns != '부가기호'`처럼 만든 불리언 배열을 `loc`에 전달하면 True인 열만 남는다.
- `drop('Unnamed: 13', axis=1)`은 열을 삭제한다. 열 이름을 리스트로 주면 여러 열을 한 번에 삭제하고, `axis`의 기본값 0은 행 삭제다.
- `dropna()`는 NaN이 하나라도 있는 행이나 열을 삭제한다. `axis=1`이면 열, `how='all'`이면 모든 값이 NaN인 열만 삭제한다.
- `inplace=True`를 주면 현재 데이터프레임이 바로 수정되지만, 내부적으로 새 객체를 만들어서 연결할 뿐이라 성능상 이득은 없다.

**불필요한 행 삭제**
- `[]` 연산자에 슬라이싱을 쓰면 행을 선택한다. `loc`은 마지막 인덱스를 포함하지만 `[]`는 포함하지 않는다.
- 행은 불리언 배열을 `[]`에 바로 넣는 방법을 가장 많이 쓴다. `ns_book[ns_book['대출건수'] > 1000]`으로 1,000회 초과 도서(2권)만 남겼다.

**중복된 데이터 처리**
- `duplicated()`는 중복된 행 중 처음 행을 뺀 나머지를 True로 표시한 불리언 배열을 반환하고, `sum()`으로 개수를 센다. 기본은 모든 열 기준이고 `subset`으로 기준 열을 정한다. '도서명', '저자', 'ISBN' 기준으로 22,096개가 나왔다.
- `keep=False`는 중복된 모든 행을 True로 표시한다. 그냥 지울 때는 `drop_duplicates()`를 쓴다.
- 이 데이터는 같은 도서가 여러 권 등록되어 있어서 삭제하지 않고 대출건수를 합쳤다. `groupby(by=[...], dropna=False).sum()`으로 합치는데, `groupby()`는 기준 열에 NaN이 있으면 그 행을 빼버리기 때문에 `dropna=False`가 필요하다.
- 합친 값을 원본에 반영하는 순서는 다음과 같다. `duplicated()`로 중복 행 표시 → `~`로 반전해 고유한 행만 `copy()` → `set_index()`로 인덱스를 맞춤 → `update()`로 대출건수 갱신 → `reset_index()`로 인덱스 해제 → `ns_book4[ns_book.columns]`로 열 순서 복원. 일부 행을 선택해서 값을 수정할 때는 `copy()`를 써야 원본이 바뀌는 문제를 막을 수 있다.

## 02. 잘못된 데이터 수정하기

**누락된 값(NaN) 확인**
- `info()`는 행 개수, 열별 NaN이 아닌 값 개수, 데이터 타입을 보여준다. `isna().sum()`은 열별 NaN 개수를 바로 센다. NaN이 아닌 값은 `notna()`로 확인한다.
- 판다스에는 NaN 값이 따로 없고 넘파이의 `np.nan`을 쓴다. 정수 열에 `None`을 넣으면 NaN으로 바뀌면서 열이 float64가 되는데, 문자열 열에는 `None`이 그대로 들어간다. 정수형으로 되돌릴 때는 `astype({'도서권수': 'int32'})`처럼 딕셔너리로 지정한다.

**누락된 값 바꾸기**
- `loc[isna() 불리언 배열, '열'] = ''`로 바꾸거나 `fillna()`를 쓴다. `fillna({'부가기호': '없음'})`처럼 딕셔너리를 주면 특정 열만 바꾸면서 전체 데이터프레임을 반환한다.
- `replace()`는 NaN뿐 아니라 어떤 값도 바꾼다. 리스트나 딕셔너리로 여러 값, 열마다 다른 값을 바꿀 수 있다.
- `regex=True`를 주면 정규 표현식을 쓴다. `\d`는 숫자, `.`은 아무 문자, `*`는 0개 이상 반복, `{2}`는 반복 횟수, `()`는 그룹이고 `\1`로 참조한다. `r'\d{2}(\d{2})'`를 `r'\1'`로 바꾸면 '2021'이 '21'이 된다.

**잘못된 값 찾아서 고치기** ('발행년도' 열)
- `astype({'발행년도': 'int32'})`가 '1988.' 같은 값 때문에 오류가 났다. `str.contains('\D', na=True)`로 숫자 이외의 문자가 있는 행을 찾으니 1,777개였다.
- `replace({'발행년도': r'.*(\d{4})'}, ...)`처럼 네 자리 숫자만 남기니 67개로 줄었다. 나머지는 바꿀 수 없어서 -1로 표시한 뒤 `astype()`을 적용했다.
- 비교 메서드 `gt()`, `ge()`, `lt()`, `le()`, `eq()`, `ne()`(각각 `>`, `>=`, `<`, `<=`, `==`, `!=`)로 이상한 연도를 찾았다. 4000년 초과가 131권이었는데 단군기원으로 보고 2333을 빼서 서기로 바꿨고, 그래도 남은 13권과 1900년 미만은 -1로 표시했다. 결국 연도를 알 수 없는 도서는 86권이었다.

**누락된 정보 채우기**
- 도서명, 저자, 출판사가 NaN이거나 발행년도가 -1인 행이 5,268개였다. ISBN으로 Yes24를 검색해 뷰티플수프로 채우는 `get_book_info()` 함수를 만들었다.
- 저자는 여러 명일 수 있어서 `find_all()`과 `join()`을 쓰고, 발행 연도는 `re.findall(r'\d{4}', ...)`로 뽑는다. 정보가 없으면 오류가 나므로 `try ~ except`로 넘어가고, `apply()`의 `result_type='expand'`로 반환값을 여러 열로 나눈다.
- `update()`로 반영하니 누락된 행이 4,615개로 653개 줄었다. 끝까지 못 채운 행은 `dropna(subset=['도서명', '저자', '출판사'])`로 삭제해서 분석에서 제외한다.
