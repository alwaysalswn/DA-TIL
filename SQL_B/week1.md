# 1️⃣ 개념 정리 

## 01. 데이터 분석이란

데이터 분석은 넓게 보면 데이터 수집, 처리, 정제, 분석, 모델링까지 전체 과정을 말하고, 좁게 보면 그중에서 기술통계, 탐색적 데이터 분석(EDA), 가설검정처럼 통계적인 분석 기법 자체만을 가리킨다는 걸 알게 됐다. 그리고 데이터 분석과 데이터 과학이 자주 헷갈렸는데, 데이터 분석은 의사결정을 돕는 통찰을 주는 데 초점이 있고 데이터 과학은 거기서 한발 더 나아가 문제 해결 솔루션을 만드는 데 초점이 있다는 차이가 있었다.

## 02. 구글 코랩과 주피터 노트북

주피터 노트북은 코드와 설명 글, 실행 결과를 한 화면에서 순서대로 볼 수 있게 해주는 도구다. 코드를 한 줄씩 셀 단위로 실행하면서 바로 결과를 확인할 수 있어서 데이터를 분석할 때 자주 쓰인다. 구글 코랩은 이 주피터 노트북을 구글 서버에서 무료로 돌릴 수 있게 해주는 서비스라서, 따로 설치할 필요 없이 브라우저만 있으면 바로 코드를 실행해볼 수 있다는 점이 편했다.

## 03. 이 도서가 얼마나 인기가 좋을까요?

이 절은 실제 사례를 통해 문제에 맞는 데이터를 찾고 다루는 과정을 배우는 부분이었다. 책 판매 데이터를 구할 수 없어서 대신 도서관 정보나루라는 공공데이터 사이트에서 남산도서관의 대출 데이터를 대안으로 찾는 과정이 인상적이었다. 그리고 gdown 패키지로 코랩에 CSV 파일을 다운로드하고, 그 파일이 EUC-KR로 인코딩되어 있어서 그냥 읽으면 오류가 난다는 것, chardet 패키지로 인코딩을 직접 확인할 수 있다는 것, 마지막으로 판다스의 read_csv() 함수로 CSV를 데이터프레임 형태로 불러오는 방법을 배웠다.

# 3️⃣ 확인 문제

## 문제 1.

> **🧚Q. 데이터 분석의 개념을 넓은 의미와 좁은 의미로 나누어 설명하고, 두 개념의 차이점도 함께 정리해주세요.**


 데이터 분석은 넓은 의미와 좁은 의미로 나눌 수 있다. 넓은 의미의 데이터 분석은 데이터 수집, 처리, 정제, 분석, 모델링까지 포함하는 전체 작업 과정을 말한다. 좁은 의미의 데이터 분석은 그중에서도 기술통계, 탐색적 데이터 분석, 가설검정처럼 통계적인 기법으로 데이터를 실제로 분석하는 작업 자체만을 가리킨다. 즉 넓은 의미는 전체 프로세스이고, 좁은 의미는 그 안의 분석 단계 하나에 한정된다는 차이가 있다.
