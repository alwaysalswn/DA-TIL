# 3️⃣ 확인 문제

## 🧩 문제 1

포켓몬 게임이나 이커머스 산업과 같이 다양한 산업에서는 각기 다른 데이터가 존재합니다. 다음 중 하나의 산업을 선택하고, 해당 산업에서 수집하고 활용될 수 있는 데이터 항목, 즉 컬럼 5가지를 자유롭게 상상하여 나열해주세요.

예시 산업:
- 온라인 음식 배달
- 스마트 헬스 케어
- 중고 거래 앱
- 교육 플랫폼

풀이 과정:

```
- 선택한 산업: 중고 거래 앱
- 떠올린 컬럼 5가지: 상품명, 가격, 판매자 아이디, 거래 상태(판매중/거래완료), 등록 날짜
- 해당 컬럼이 필요하다고 생각한 이유: 무엇을 얼마에 파는지, 누가 올렸는지, 지금 살 수 있는 상태인지, 언제 올라온 글인지를 알아야 거래가 가능하기 때문에 필요하다고 생각했다.
```

## 🧩 문제 2

이번 강의를 통해 SQL이 왜 필요하다고 느끼는지, SQL을 통해 본인이 어떤 것을 해내고 싶은지를 자유롭게 작성해주세요.

풀이 과정:

```
- SQL이 필요하다고 느낀 이유: 데이터가 많아지면 엑셀만으로는 원하는 조건으로 걸러내는 데 한계가 있을 것 같아서 SQL이 필요하다고 느꼈다.
- SQL로 해보고 싶은 일: 나중에 관심 있는 분야인 금융 도메인의 데이터를 직접 쿼리로 뽑아서 어떤 패턴이 있는지 확인해보고 싶다.
- 앞으로 SQL을 공부할 때 기대되는 점: 숫자로 된 데이터를 직접 다뤄보면서 데이터를 근거로 설명하는 능력을 키우고 싶다.
```
