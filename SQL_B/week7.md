## 01.

```
개념 이름: GROUP BY
개념 설명: 같은 값끼리 모아서 그룹화하는 구문. 특정 컬럼을 기준으로 모으면서 다른 컬럼은 집계함수(COUNT, SUM, AVG, MAX, MIN)로 계산할 수 있음. SELECT에 쓴 집계 안 한 컬럼은 반드시 GROUP BY에도 작성해야 하고, 중복 없는 값만 보고 싶으면 DISTINCT를 씀
예시 쿼리:
SELECT
  type1,
  AVG(attack) AS avg_attack,
  COUNT(type1) AS pokemon_cnt
FROM basic.pokemon
GROUP BY type1
# type1(타입)을 기준으로 그룹화해서 타입별 평균 공격력과 포켓몬 수를 집계
```

## 02.

```
개념 이름: HAVING (WHERE와의 차이)
개념 설명: GROUP BY로 집계한 뒤의 결과에 조건을 걸 때 쓰는 구문. WHERE는 테이블(Raw Data)에 바로 조건을 설정하는 거라 집계 전에 적용되고, HAVING은 그룹화한 값에 조건을 설정하는 거라 집계 후에 적용됨. 그래서 COUNT 같은 집계 결과로 거르려면 WHERE가 아니라 HAVING을 써야 함
예시 쿼리:
SELECT
  type1,
  COUNT(type1) AS pokemon_cnt
FROM basic.pokemon
GROUP BY type1
HAVING pokemon_cnt >= 10
# 타입별 포켓몬 수를 센 뒤 10마리 이상인 타입만 남김
```

## (선택) 03.

```
개념 이름: ORDER BY
개념 설명: 결과를 정렬하는 구문으로 ASC(오름차순, 기본값), DESC(내림차순)를 지정. 쿼리의 맨 마지막에만 작성하면 되고(LIMIT보다는 앞), 컬럼을 쉼표로 여러 개 적으면 앞의 컬럼으로 먼저 정렬하고 값이 같을 때 다음 컬럼으로 정렬함
아직 헷갈리는 점: 여러 기준으로 정렬할 때 DESC가 바로 앞 컬럼에만 적용되는 건지, 뒤 컬럼까지 같이 적용되는 건지. (ORDER BY NAME, DATETIME DESC라면 NAME은 오름차순, DATETIME만 내림차순이 맞는지 문제 1로 직접 확인함)
```

# 3️⃣ 복습 문제

프로그래머스는 로그인이 필요하므로, 로그인 후 문제 풀이를 진행해주세요.

## 🧩 문제 1

문제 링크: [여러 기준으로 정렬하기](https://school.programmers.co.kr/learn/courses/30/lessons/59404)

풀이 과정:

```
- 문제 요구사항: ANIMAL_INS에서 동물의 아이디와 이름, 보호 시작일을 이름 순으로 조회. 단, 이름이 같으면 보호를 나중에 시작한 동물을 먼저 보여줌
- 첫 번째 정렬 기준: NAME 오름차순 (ASC는 기본값이라 생략)
- 두 번째 정렬 기준: DATETIME 내림차순 (나중에 시작한 것이 먼저 = 최신순)
- 복습한 점: ORDER BY에 컬럼을 쉼표로 여러 개 쓰면 앞에서부터 우선순위가 정해지고, DESC는 바로 앞 컬럼에만 적용됨

SELECT ANIMAL_ID, NAME, DATETIME
FROM ANIMAL_INS
ORDER BY NAME, DATETIME DESC;
```

## 🧩 문제 2

문제 링크: [동명 동물 수 찾기](https://school.programmers.co.kr/learn/courses/30/lessons/59041)

풀이 과정:

```
- 그룹화 기준: NAME (이름이 같은 동물끼리 묶어서 개수를 셈)
- 제외해야 하는 값: 이름이 NULL인 동물. COUNT(NAME)은 NULL을 세지 않아서 따로 조건을 쓰지 않아도 결과에서 빠짐
- HAVING 조건: 이름이 같은 동물이 2마리 이상, 즉 COUNT(NAME) >= 2
- 복습한 점: 집계한 결과(COUNT)로 거를 때는 WHERE가 아니라 HAVING을 써야 하고, 결과를 이름 순으로 정렬하려면 ORDER BY를 맨 마지막에 둠

SELECT NAME, COUNT(NAME) AS COUNT
FROM ANIMAL_INS
GROUP BY NAME
HAVING COUNT(NAME) >= 2
ORDER BY NAME;
```
